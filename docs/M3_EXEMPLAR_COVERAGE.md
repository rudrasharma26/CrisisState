# M3 — Exemplar Coverage Matrix

## Target

Default target: 10 exemplars per canonical value.

Use 15 for values identified as linguistically difficult during review.

## Claim Coverage

| Claim Type | Values Covered | Target |
|---|---|---:|
| FLOODED | Every existing canonical value | 10/value |
| ROAD_ACCESS | Every existing canonical value | 10/value |
| WATER_LEVEL | Every existing canonical value | 10/value |
| PEOPLE_TRAPPED | Every existing canonical value | 10/value |
| BUILDING_DAMAGE | Every existing canonical value | 10/value |
| EVACUATION | Every existing canonical value | 10/value |
| TRAFFIC_STATUS | Every existing canonical value | 10/value |

## Diversity Target Per Value

Where 10 exemplars are used:

- 3 short/simple formulations
- 3 natural report-style formulations
- 2 strong paraphrases
- 1 less-common wording pattern
- 1 structurally different formulation

The examples must express the same canonical meaning.

## Selection Rules

Exemplars must:

- represent one primary claim
- map clearly to one canonical value
- resemble realistic flood-disaster reporting language
- vary wording and syntax
- avoid superficial rewrites
- avoid unnecessary location/time details
- remain independent of evaluation examples

## Expansion Rule

Increase a value from 10 to 15 only when retrieval evaluation or manual review shows meaningful linguistic coverage gaps.

Do not increase the bank merely to increase its size.

## Scope Boundary

M3 uses the existing Phase 1 canonical vocabulary.

No new canonical values are introduced.

Qualified/modal semantics beyond existing schema support remain part of later milestones, especially M5/M6.
